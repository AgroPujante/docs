Base: `/api/v1`.

## Erros comuns

Shapes de erro (`{detail, code}`), 422 do Pydantic e o 429 do slowapi seguem as [convenções da API](/agropujante/convencoes). **Específico desta página**: a busca de jurisprudência tem 429 **de regra de negócio** além do slowapi — limite mensal do plano e limite diário do provedor vêm como `HTTPException` no shape `{detail, code}`, com mensagens distintas (exemplos no accordion de `/jurisprudencia/search`).

<Warning>
**Três conceitos distintos** — não os misture ao trabalhar nesses routers:

1. **Consulta de jurisprudência** (`/jurisprudencia`) — busca de decisões em tribunais via **jurisprudencias.ai**. É uma ferramenta de pesquisa, não conteúdo do portal.
2. **Julgados** — posts **editoriais** (tipo de post no router `/posts`) que comentam decisões. Não aparecem nesta página.
3. **Boletins** (`/boletins`) — PDFs **curados** de julgados, com gating PRO. As rows da tabela `julgados` pertencem a boletins — não são os posts editoriais.
</Warning>

## Boletins — público (`/boletins`)

| Método | Path | Descrição | Auth |
|---|---|---|---|
| GET | `/boletins` | Publicados, paginados — free recebe só o `sample_julgado` de cada um | Público |
| GET | `/boletins/{slug}` | Detalhe — `julgados[]` completo apenas para PRO/apoiador | Público/PRO |
| GET | `/boletins/{slug}/download` | Signed URL do PDF | PRO+ |

## Boletins — admin (`/admin/boletins`)

<Info>
Os exemplos de POST/PATCH/DELETE abaixo são ilustrativos — confirme o ambiente antes de rodar em produção: `publish` dispara a criação de campanha de newsletter e `archive`/`DELETE` tiram boletim do ar.
</Info>

| Método | Path | Descrição | Auth |
|---|---|---|---|
| POST | `/admin/boletins` | Cria boletim | admin+ |
| GET | `/admin/boletins` | Todos os status | admin+ |
| GET | `/admin/boletins/{id}` | Detalhe | admin+ |
| PATCH | `/admin/boletins/{id}` | Edita | admin+ |
| POST | `/admin/boletins/{id}/upload-pdf` | Sobe o PDF | admin+ |
| POST | `/admin/boletins/{id}/upload-cover` | Sobe a capa | admin+ |
| POST | `/admin/boletins/{id}/publish` | Publica | admin+ |
| POST | `/admin/boletins/{id}/archive` | Arquiva (tira do ar sem apagar) | admin+ |
| DELETE | `/admin/boletins/{id}` | Remove | admin+ |

## Consulta de jurisprudência (`/jurisprudencia`)

Integração com **jurisprudencias.ai** (`JURISPRUDENCIAS_AI_API_KEY`).

| Método | Path | Descrição | Auth |
|---|---|---|---|
| GET | `/jurisprudencia/tribunais` | Lista cortes (STF, STJ, TRF...) | Público |
| GET | `/jurisprudencia/estados` | Estados + mapping de tribunais | Público |
| GET | `/jurisprudencia/estados/{estado}/tribunais` | Tribunais do estado | Público |
| POST | `/jurisprudencia/search` | Busca de decisões (rate-limited) | JWT |
| GET | `/jurisprudencia/{tribunal_code}/{juris_id}` | Detalhe da decisão | JWT |

<Note>
A busca exige login e tem rate limit próprio (slowapi) — cada query consome a API externa.
</Note>

## Pastas do usuário (`/juris-folders`)

O usuário organiza decisões encontradas na consulta em pastas pessoais (RLS: só as próprias).

| Método | Path | Descrição | Auth |
|---|---|---|---|
| GET | `/juris-folders` | Pastas do usuário | JWT |
| POST | `/juris-folders` | Cria pasta | JWT |
| GET | `/juris-folders/by-slug/{slug}` | Pasta por slug | JWT |
| GET | `/juris-folders/{folder_id}/items` | Itens salvos da pasta | JWT |
| POST | `/juris-folders/{folder_id}/items` | Salva decisão na pasta | JWT |
| DELETE | `/juris-folders/{folder_id}/items/{item_id}` | Remove item da pasta | JWT |
| GET | `/juris-folders/saved-map` | Mapa de decisões já salvas | JWT |
| PATCH | `/juris-folders/{folder_id}` | Renomeia/edita | JWT |
| DELETE | `/juris-folders/{folder_id}` | Remove | JWT |

<Note>
O prefixo real do router é `/juris-folders` (hífen). Além do JWT, todos os endpoints exigem plano PRO ou Apoiador (403 abaixo).
</Note>
