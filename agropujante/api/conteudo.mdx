Base: `/api/v1`. `editor+`, `gestor+`, `admin+` = role mínimo via `admin_users`.

## Erros comuns

O handler global adiciona `code` ao body (`http_error` para `HTTPException`; `not_found`/`forbidden`/`conflict` para as exceptions de domínio de `core/exceptions.py`):

```json title="401 Unauthorized — sem credencial"
{ "detail": "Não autenticado", "code": "http_error" }
```

```json title="401 Unauthorized — token ruim"
{ "detail": "Token inválido ou expirado", "code": "http_error" }
```

```json title="403 Forbidden — role insuficiente (editor+/gestor+/admin+)"
{ "detail": "Acesso negado — permissão insuficiente", "code": "http_error" }
```

```json title="404 Not Found — recurso de domínio"
{ "detail": "Post não encontrado", "code": "not_found" }
```

```json title="422 Unprocessable Entity — validação Pydantic (shape padrão FastAPI)"
{
  "detail": [
    {
      "type": "string_too_short",
      "loc": ["body", "title"],
      "msg": "String should have at least 1 character",
      "input": ""
    }
  ]
}
```

## Posts (`/posts`)

| Método | Path | Descrição | Auth |
|---|---|---|---|
| GET | `/posts/trending` | Top dos últimos 7 dias (cache 15 min) | Público |
| GET | `/posts` | Lista paginada — `?type`, `?category_slug`, `?featured`, `?column_id` (cache 60 s) | Público |
| GET | `/posts/featured` | Destaques (cache 60 s) | Público |
| GET | `/posts/search?q=` | Busca full-text simples | Público |
| GET | `/posts/{slug}` | Detalhe por slug + access control (artigo com blur para free; notícia ilimitada; cache 60 s) | Público |
| GET | `/posts/admin/list` | Todos os posts, inclusive drafts | editor+ |
| GET | `/posts/admin/{post_id}` | Por ID, qualquer status | editor+ |
| POST | `/posts` | Cria post | editor+ |
| PATCH | `/posts/{post_id}` | Edita | editor+ |
| DELETE | `/posts/{post_id}` | Remove | gestor+ |
| PUT | `/posts/{post_id}/authors` | Define autores (N:N) | editor+ |
| PUT | `/posts/{post_id}/tags` | Define tags (N:N) | editor+ |

## Catálogos editoriais

| Método | Path | Descrição | Auth |
|---|---|---|---|
| GET | `/authors` | Lista autores (cache) | Público |
| GET | `/authors/{slug}` | Autor + posts | Público |
| POST/PATCH/DELETE | `/authors`, `/authors/{author_id}` | CRUD de autores | admin+ |
| GET | `/columns` / `/columns/{slug}` | Colunas editoriais | Público |
| POST/PATCH/DELETE | `/columns`, `/columns/{column_id}` | CRUD de colunas | admin+ |
| GET | `/categories` | Categorias (não há GET por id) | Público |
| POST/PATCH/DELETE | `/categories`, `/categories/{category_id}` | CRUD de categorias | admin+ |
| GET | `/tags` | Tags | Público |
| POST/PATCH/DELETE | `/tags`, `/tags/{tag_id}` | CRUD de tags | admin+ |
