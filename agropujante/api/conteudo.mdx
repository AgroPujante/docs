Base: `/api/v1`. `editor+`, `gestor+`, `admin+` = role mínimo via `admin_users`.

## Posts (`/posts`)

| Método | Path | Descrição | Auth |
|---|---|---|---|
| GET | `/posts/trending` | Top dos últimos 7 dias (cache 15 min) | Público |
| GET | `/posts` | Lista paginada — `?type`, `?category_slug`, `?featured`, `?column_id` (cache 60 s) | Público |
| GET | `/posts/featured` | Destaques (cache 60 s) | Público |
| GET | `/posts/search?q=` | Busca full-text simples | Público |
| GET | `/posts/{slug}` | Detalhe por slug + access control (artigo com blur para free; notícia ilimitada; cache 60 s) | Público |
| GET | `/posts/admin/list` | Todos os posts, inclusive drafts | editor+ |
| GET | `/posts/admin/{post_id}` | Por ID, qualquer status | editor+ |
| POST | `/posts` | Cria post | editor+ |
| PATCH | `/posts/{post_id}` | Edita | editor+ |
| DELETE | `/posts/{post_id}` | Remove | gestor+ |
| PUT | `/posts/{post_id}/authors` | Define autores (N:N) | editor+ |
| PUT | `/posts/{post_id}/tags` | Define tags (N:N) | editor+ |

## Search (`/search`)

| Método | Path | Descrição | Auth |
|---|---|---|---|
| GET | `/search?q=&type=&category=&tags=&date_from=&date_to=&sort=&semantic=` | Busca avançada fuzzy + embeddings (cache 30 s) | Público |

Com `semantic=true`, a busca combina full-text fuzzy com similaridade vetorial (pgvector, embeddings OpenAI `text-embedding-3-small`, índice HNSW).
