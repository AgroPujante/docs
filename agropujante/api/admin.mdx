Base: `/api/v1`.

## Erros comuns

Shapes de erro (`{detail, code}`), 422 do Pydantic e o 429 do slowapi seguem as [convenções da API](/agropujante/convencoes). Específico desta página: usar **API key em método de escrita** devolve 403 com `"API key é somente leitura — apenas requisições GET são permitidas"`, e `POST /analytics/pageview` é limitado a `60/minute` por IP.

<Info>
Os exemplos de POST/PATCH/DELETE desta página alteram permissões, chaves e arquivos reais (admin-users, api-keys, storage). São ilustrativos — confirme o ambiente antes de rodar em produção.
</Info>

<Accordion title="POST /api/v1/analytics/pageview">
Fire-and-forget — responde **sempre** 204, mesmo descartando (bot ou path bloqueado: `/admin`, `/api`, `/obrigado`). Rate limit `60/minute`.

```bash title="Requisição"
curl -X POST "https://api.agropujante.com.br/api/v1/analytics/pageview" \
  -H "Content-Type: application/json" \
  -d '{
    "path": "/artigo/marco-temporal-seguranca-juridica-no-campo",
    "visitor_id": "vis_8f2a91c7",
    "session_id": "sess_31bd07",
    "utm_source": "newsletter",
    "utm_medium": "email",
    "referrer": "https://news.agropujante.com.br"
  }'
```

```text title="204 No Content"
(sem body)
```
</Accordion>

<Accordion title="POST /api/v1/admin-users">
Cria o usuário no Supabase Auth (email confirmado automaticamente) + row em `admin_users`. `role_id`: `administrador` | `gestor` | `editor`.

```bash title="Requisição"
curl -X POST "https://api.agropujante.com.br/api/v1/admin-users" \
  -H "Authorization: Bearer <TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{"email": "novo.editor@exemplo.com.br", "password": "S3nhaForte1", "role_id": "editor"}'
```

## Webhooks (`/webhooks`)

| Método | Path | Descrição | Auth |
|---|---|---|---|
| POST | `/webhooks/resend` | Status de entrega/abertura/clique de email → `email_sends` / `email_click_events` | Assinatura Resend |

<Warning>
O webhook de pagamento do Asaas no Portal vive em `POST /subscriptions/webhook` (ver [Monetização](/agropujante/api/monetizacao)) — não existe rota `/webhooks/asaas` nem tabela `asaas_webhooks_log` neste backend. O Portal processa o evento direto, sem tabela de auditoria de webhook (diferente da Escola, que audita em `asaas_webhook_events`).
</Warning>

<AccordionGroup>
<Accordion title="POST /api/v1/webhooks/resend">
Validação por assinatura **Svix** (headers `svix-id`, `svix-timestamp`, `svix-signature` + `RESEND_WEBHOOK_SECRET`). Eventos tratados: `email.delivered`, `email.opened`, `email.clicked`, `email.bounced`, `email.complained`.

```bash title="Requisição (payload enviado pelo Resend)"
curl -X POST "https://api.agropujante.com.br/api/v1/webhooks/resend" \
  -H "Content-Type: application/json" \
  -H "svix-id: msg_2hXk91mPq" \
  -H "svix-timestamp: 1781200000" \
  -H "svix-signature: v1,<TOKEN>" \
  -d '{
    "type": "email.clicked",
    "created_at": "2026-06-12T10:05:00.000Z",
    "data": {
      "email_id": "re_3kLm82nQr7",
      "to": ["ana.carvalho@exemplo.com.br"],
      "click": {
        "link": "https://agropujante.com.br/decisoes/penhora-de-safra-futura-em-execucao-de-cpr?utm_campaign=semanal",
        "ipAddress": "203.0.113.10",
        "userAgent": "Mozilla/5.0 ..."
      }
    }
  }'
```

```json title="200 OK"
{ "ok": true, "event": "email.clicked" }
```

```json title="200 OK — evento não rastreado (ignorado sem retry)"
{ "ok": true, "skipped": "event_not_tracked" }
```

```json title="401 Unauthorized — assinatura inválida"
{ "detail": "Invalid signature", "code": "http_error" }
```

```json title="400 Bad Request — sem headers svix"
{ "detail": "Missing svix headers", "code": "http_error" }
```
</Accordion>

<Accordion title="POST /api/v1/subscriptions/webhook (Asaas)">
No código atual o webhook do Asaas vive em `/subscriptions/webhook` (não em `/webhooks/asaas`). Valida o header `asaas-access-token` e sempre responde 200 após aceitar o evento — exemplo completo de payload na página de [monetização](/agropujante/api/monetizacao#subscriptions-subscriptions).

