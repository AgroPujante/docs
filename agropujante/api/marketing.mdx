Base: `/api/v1`.

## Erros comuns

Shapes de erro (`{detail, code}`), 422 do Pydantic e o 429 do slowapi seguem as [convenções da API](/agropujante/convencoes). Específico desta página: o subscribe público da newsletter é limitado a `5/minute` por IP.

## Newsletter pública (`/newsletter`)

| Método | Path | Descrição | Auth |
|---|---|---|---|
| POST | `/newsletter/subscribe` | Inscreve email | Público |
| POST | `/newsletter/unsubscribe` | Remove inscrição | Público |
| GET | `/newsletter` | Status de inscrição do usuário | JWT |

<Note>
No código atual o status de inscrição do usuário logado vem no campo `newsletter_subscribed` de `GET /users/me`; a remoção de inscrito é `DELETE /newsletter/{subscriber_id}` (gestor+).
</Note>

<AccordionGroup>
<Accordion title="POST /api/v1/newsletter/subscribe">
Rate limit: `5/minute`. `terms_accepted: true` é obrigatório (422 se faltar).

```bash title="Requisição"
curl -X POST "https://api.agropujante.com.br/api/v1/newsletter/subscribe" \
  -H "Content-Type: application/json" \
  -d '{
    "email": "roberto.nogueira@exemplo.com.br",
    "name": "Roberto Nogueira",
    "profession": "Produtor rural",
    "terms_accepted": true
  }'
```

```json title="201 Created"
{
  "id": "6c7d8e9f-0a1b-4c2d-3e4f-5a6b7c8d9e0f",
  "email": "roberto.nogueira@exemplo.com.br",
  "name": "Roberto Nogueira",
  "phone": null,
  "profession": "Produtor rural",
  "subscribed_at": "2026-06-12T17:00:00+00:00",
  "is_active": true,
  "mailchimp_synced_at": null
}
```

Erros genéricos (422, 429): ver [convenções da API](/agropujante/convencoes).
</Accordion>

<Accordion title="DELETE /api/v1/newsletter/{subscriber_id}">
Remove a inscrição (gestor+).

```bash title="Requisição"
curl -X DELETE "https://api.agropujante.com.br/api/v1/newsletter/6c7d8e9f-0a1b-4c2d-3e4f-5a6b7c8d9e0f" \
  -H "Authorization: Bearer <TOKEN>"
```

O router também expõe `GET /newsletter/by-slug/{slug}` (HTML público da campanha enviada, 60/min), `GET /newsletter/subscribers` e `GET /newsletter/subscribers/export` (CSV, ambos gestor+).
</Accordion>

## Admin newsletters (`/admin/newsletters`)

Gestão completa de campanhas — ciclo draft → test → send → tracking (ver [fluxo de campanha](/agropujante/fluxos#campanha-de-email)). Tudo admin+.

<Warning>
`POST /admin/newsletters/{id}/send` dispara email para a **lista real** (milhares de inscritos) — os exemplos são ilustrativos; confirme o ambiente e o `segment` antes de rodar. Para validar, use `/test` (até 5 emails) ou `/send-custom` (até 50).
</Warning>

| Método | Path | Descrição | Auth |
|---|---|---|---|
| POST | `/admin/newsletters` | Cria campanha | admin+ |
| GET | `/admin/newsletters` | Lista paginada | admin+ |
| GET | `/admin/newsletters/{id}` | Detalhe | admin+ |
| PATCH | `/admin/newsletters/{id}` | Edita | admin+ |
| DELETE | `/admin/newsletters/{id}` | Remove | admin+ |
| POST | `/admin/newsletters/{id}/test` | Envia email de teste | admin+ |
| POST | `/admin/newsletters/{id}/send-custom` | Envia para lista custom | admin+ |
| POST | `/admin/newsletters/{id}/send` | Enfileira para a lista | admin+ |
| POST | `/admin/newsletters/{id}/cancel` | Cancela envio em andamento | admin+ |
| GET | `/admin/newsletters/{id}/pdf` | Preview em PDF | admin+ |
| POST | `/admin/newsletters/{id}/generate-boletim-pdf` | Gera PDF de boletim para a campanha | admin+ |
| GET | `/admin/newsletters/{id}/analytics` | Open/click da campanha | admin+ |
| GET | `/admin/newsletters/{id}/ratings` | NPS da campanha | admin+ |
| GET | `/admin/newsletters/{id}/top-links` | Links mais clicados | admin+ |
| GET | `/admin/newsletters/recipients/preview` | Preview dos destinatários | admin+ |
| GET | `/admin/newsletters/analytics/overview` | Visão geral de analytics | admin+ |
| GET | `/admin/newsletters/analytics/summary` | Resumo agregado | admin+ |

<AccordionGroup>
<Accordion title="GET /r/{tracking_code}">
Montado **fora** do `/api/v1` (prefixo `/r`). Os tracking codes são rotas fixas: `wa-cashback`, `news-pro`, `news-apoiador`. Cada uma seta cookies `pujante_utm_*` (domínio `.agropujante.com.br`, 30 dias) e responde 302.

```bash title="Requisição"
curl -i "https://api.agropujante.com.br/r/wa-cashback?u=9a1d4f22-3b5c-4e7d-8f90-1a2b3c4d5e6f"
```

```text title="302 Found"
Location: https://wa.me/556298563333?text=Oi%21%20Vi%20no%20email%20do%20Plano%20Pujante%20Anual...
Set-Cookie: pujante_utm_source=whatsapp; Domain=.agropujante.com.br; Max-Age=2592000; Path=/; SameSite=lax; Secure
Set-Cookie: pujante_utm_medium=email; ...
Set-Cookie: pujante_utm_campaign=pro_annual_cashback; ...
```

`news-pro` → 302 para `/pujante-pro` (campaign `semanal_AAAAMMDD`); `news-apoiador` → 302 para `/apoiadores`.
