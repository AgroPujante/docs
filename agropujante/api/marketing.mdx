Base: `/api/v1`.

## Newsletter pública (`/newsletter`)

| Método | Path | Descrição | Auth |
|---|---|---|---|
| POST | `/newsletter/subscribe` | Inscreve email | Público |
| POST | `/newsletter/unsubscribe` | Remove inscrição | Público |
| GET | `/newsletter` | Status de inscrição do usuário | JWT |

## Admin newsletters (`/admin/newsletters`)

Gestão completa de campanhas — ciclo draft → test → send → tracking (ver [fluxo de campanha](/agropujante/fluxos#campanha-de-email)). Tudo admin+.

| Método | Path | Descrição | Auth |
|---|---|---|---|
| POST | `/admin/newsletters` | Cria campanha | admin+ |
| GET | `/admin/newsletters` | Lista paginada | admin+ |
| GET | `/admin/newsletters/{id}` | Detalhe | admin+ |
| PATCH | `/admin/newsletters/{id}` | Edita | admin+ |
| DELETE | `/admin/newsletters/{id}` | Remove | admin+ |
| POST | `/admin/newsletters/{id}/test` | Envia email de teste | admin+ |
| POST | `/admin/newsletters/{id}/send-custom` | Envia para lista custom | admin+ |
| POST | `/admin/newsletters/{id}/send` | Enfileira para a lista | admin+ |
| POST | `/admin/newsletters/{id}/cancel` | Cancela envio em andamento | admin+ |
| GET | `/admin/newsletters/{id}/pdf` | Preview em PDF | admin+ |
| POST | `/admin/newsletters/{id}/generate-boletim-pdf` | Gera PDF de boletim para a campanha | admin+ |
| GET | `/admin/newsletters/{id}/analytics` | Open/click da campanha | admin+ |
| GET | `/admin/newsletters/{id}/ratings` | NPS da campanha | admin+ |
| GET | `/admin/newsletters/{id}/top-links` | Links mais clicados | admin+ |
| GET | `/admin/newsletters/recipients/preview` | Preview dos destinatários | admin+ |
| GET | `/admin/newsletters/analytics/overview` | Visão geral de analytics | admin+ |
| GET | `/admin/newsletters/analytics/summary` | Resumo agregado | admin+ |

## Vitrine do site

## Redirects (`/r/{tracking_code}`)

| Método | Path | Descrição | Auth |
|---|---|---|---|
| GET | `/r/{tracking_code}` | Redirect público com tracking UTM (links de campanha) | Público |

## OG/SEO (`/og`)

| Método | Path | Descrição | Auth |
|---|---|---|---|
| GET | `/og/{type}/{slug}` | HTML com OG tags para bots (`noticia`/`artigo`/`julgado`); 301 para slugs antigos | Público |

Consumido pelo `server.js` Express quando detecta crawler — ver [Arquitetura](/agropujante/arquitetura#serverjs-og-proxy-e-spa-fallback).
