O **AgroPujante** é o portal jurídico do agronegócio: um veículo de conteúdo editorial em produção com cerca de **3 mil visitas por dia**. Você está documentando um produto vivo — toda decisão técnica aqui assume tráfego real.

<Warning>
O AgroPujante **não é** uma landing page e **não é** a Escola Pujante. São projetos separados. O portal publica conteúdo editorial e vende assinatura PRO; a Escola é um LMS com mentoria, documentada em outra seção.
</Warning>

## Stack

| Camada | Tecnologia |
|---|---|
| Frontend | React 19 + Vite + Tailwind 4 |
| Backend | FastAPI (Python), base `/api/v1` |
| Banco | Supabase Postgres, schema `pujante` |
| Hospedagem | Railway (front e back) |
| Servidor de borda do front | Express (`server.js`) — injeção de OG tags para bots + fallback de SPA |

O frontend conversa com o backend FastAPI **e também** diretamente com o PostgREST do Supabase (anon key + RLS, header `Accept-Profile: pujante`) para leituras públicas simples. Os detalhes estão em [Arquitetura](/agropujante/arquitetura).

## Tipos de conteúdo

  </Card>
  <Card title="Boletim" icon="file-pdf">

  </Card>
</CardGroup>

## Jurisprudência ≠ julgados ≠ boletins

Essa distinção causa confusão recorrente. São **três coisas distintas**:

| Conceito | O que é | Onde vive |
|---|---|---|
| **Consulta de jurisprudência** | Busca de decisões em tribunais (STF, STJ, TRFs...) via integração com **jurisprudencias.ai** | `/jurisprudencia` no site, router `/jurisprudencia` na API |
| **Julgados** | Posts **editoriais** (tipo de post) que comentam decisões | Tabela `posts` com `type=julgado` |
| **Boletins** | PDFs **curados** de julgados, com gating PRO | Tabelas `boletins` + `julgados` |

Quando alguém pedir algo sobre "jurisprudência", confirme qual dos três é o alvo antes de mexer.
