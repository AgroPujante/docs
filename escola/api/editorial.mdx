Base: `/api/v2/noticias`. Módulo usado pelo time editorial (role `EDITORIAL` tem acesso a notícias, artigos e calendário; ações de escrita aqui exigem MANAGER).

## Notícias

| Método | Path | Descrição | Auth |
|---|---|---|---|
| GET | `/noticias` | Listar (`?status`, `?sigla`, `?favorito`, `?busca`, `?page`, `?pageSize`, `?limit`) | JWT |
| GET | `/noticias/estatisticas` | Estatísticas gerais | JWT |
| GET | `/noticias/{noticia_id}` | Detalhe | JWT |
| PATCH | `/noticias/{noticia_id}` | Atualizar status/favorito/notas | MANAGER |

### PATCH /noticias/\{noticia_id\}

<ParamField body="status" type="string">`NOVA` ou `USADA`.</ParamField>
<ParamField body="favorito" type="boolean">Marcar como favorita.</ParamField>
<ParamField body="notas" type="string">Notas internas.</ParamField>

## Tags

| Método | Path | Descrição | Auth |
|---|---|---|---|
| GET | `/noticias/tags` | Listar tags do catálogo | JWT |
| POST | `/noticias/tags` | Criar tag | MANAGER |
| POST | `/noticias/{noticia_id}/tags/{tag_id}` | Vincular tag à notícia | MANAGER |

| GET | `/noticias/{noticia_id}/tags` | Tags de uma notícia | JWT |

### POST /noticias/tags

<ParamField body="nome" type="string" required>Nome da tag.</ParamField>
