Base: `/api/v2/noticias`. Módulo usado pelo time editorial (role `EDITORIAL` tem acesso a notícias, artigos e calendário; ações de escrita aqui exigem MANAGER).

## Erros comuns

Os erros genéricos da API v2 (401/403/422, shape `{detail, code}`) estão em [Convenções da API](/escola/convencoes) — abaixo, apenas os específicos de cada endpoint.

## Notícias

| Método | Path | Descrição | Auth |
|---|---|---|---|

| GET | `/noticias/{noticia_id}` | Detalhe | JWT |
| PATCH | `/noticias/{noticia_id}` | Atualizar status/favorito/notas | MANAGER |
