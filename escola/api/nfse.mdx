Grupo `/bling` — emissão e gestão de notas fiscais de serviço via Bling: conexão OAuth, NFe, KPIs e estatísticas sobre `bling_invoices`, configuração fiscal (NFSe e por produto) e automação de emissão. Dashboards de receita estão em [Financeiro — dashboards](/escola/api/financeiro-dashboards) e o billing dos gateways em [Billing](/escola/api/billing).

## Erros comuns

Os erros genéricos da API v2 (401/403/422, shape `{detail, code}`) estão em [Convenções da API](/escola/convencoes) — abaixo, apenas os específicos de cada endpoint.

## Bling / NFSe (`/bling`)

| Método | Path | Descrição | Auth |
|---|---|---|---|
| GET | `/bling/authorize` | Iniciar OAuth Bling | ADMIN |
| GET | `/bling/callback` | Callback OAuth | Público |
| GET | `/bling/status` | Status da conexão | ADMIN |
| POST | `/bling/nfe` | Criar NFe | ADMIN |
| POST | `/bling/nfe/{id}/enviar` | Enviar NFe | ADMIN |
| POST | `/bling/nfe/{id}/cancelar` | Cancelar NFe | ADMIN |
| GET | `/bling/nfe/{id}` | Detalhe NFe | ADMIN |
| GET | `/bling/nfe` | Listar NFe | ADMIN |
| GET | `/bling/invoices/kpis` | KPIs de notas | MANAGER |
| GET | `/bling/invoices/monthly-stats` | Stats mensais | MANAGER |
| GET | `/bling/invoices` | Listar notas (`?page`, `?limit`, `?status`, `?search`, `?dateFrom`, `?dateTo`) | MANAGER |
| GET | `/bling/nfse-config` | Configuração NFSe | ADMIN |
| PUT | `/bling/nfse-config` | Atualizar config NFSe | ADMIN |
| GET | `/bling/product-configs` | Configs fiscais por produto | ADMIN |
| PUT | `/bling/product-configs/{product_id}` | Upsert de config fiscal | ADMIN |
| GET | `/bling/automation/config` | Config da automação | ADMIN |
| PUT | `/bling/automation/config` | Atualizar automação | ADMIN |
| GET | `/bling/automation/logs` | Logs da automação (`?page`, `?limit`) | ADMIN |
| POST | `/bling/webhook` | Webhook Bling | Público |

<Warning>
Retornam **501 — não implementado**: `/authorize`, `/callback`, `/status`, todas as rotas `/nfe*` e `POST /webhook`.
</Warning>

Os endpoints 501 deste grupo respondem com o template:

```json title="501 Not Implemented (template)"
{ "detail": "Endpoint Bling nao migrado. Use Nest legado. Equivalente: BlingService.<metodo>", "code": "http_error" }
```

### PUT /bling/nfse-config

<ParamField body="cnpj" type="string">CNPJ do emissor.</ParamField>
<ParamField body="razaoSocial" type="string">Razão social.</ParamField>
<ParamField body="inscricaoMunicipal" type="string">Inscrição municipal — além de demais campos fiscais (CNAE, código de serviço, alíquota ISS, código NBS).</ParamField>

### PUT /bling/product-configs/\{product_id\}

<ParamField body="fiscalDescription" type="string">Descrição fiscal do serviço.</ParamField>
<ParamField body="serviceCode" type="string">Código de serviço municipal.</ParamField>
<ParamField body="codigoNbs" type="string">Código NBS.</ParamField>
<ParamField body="active" type="boolean">Emissão ativa para o produto.</ParamField>

### PUT /bling/automation/config

<ParamField body="enabled" type="boolean">Automação de emissão ligada.</ParamField>
<ParamField body="products" type="array">Produtos incluídos na automação.</ParamField>
