## Mentored tracking (`/mentored-tracking`)

Rotas `my-*` são a visão do **mentorado** (aluno); as demais são da equipe (MANAGER).

### Visão do mentorado

| Método | Path | Descrição | Auth |
|---|---|---|---|
| GET | `/mentored-tracking/my-profile` | Meu perfil de mentorado | JWT |
| PUT | `/mentored-tracking/my-profile` | Atualizar perfil (flat: `gender`, `whatsapp`, `birthDate`, `cep`, `address`, `discAnswers`, ...) | JWT |
| GET | `/mentored-tracking/my-tests-status` | Status dos testes (DISC, socioemocional, etc.) | JWT |
| GET | `/mentored-tracking/my-tasks-status` | Status das tarefas (`?month`) | JWT |
| PUT | `/mentored-tracking/my-tasks/{task_number}` | Marcar/desmarcar tarefa | JWT |
| GET | `/mentored-tracking/my-available-months` | Meses disponíveis | JWT |
| GET | `/mentored-tracking/my-action-plan` | Plano de ação (`?referenceMonth`) | JWT |
| POST | `/mentored-tracking/my-action-plan/save-pdf` | Exportar plano em PDF | JWT |

<Warning>
`POST /mentored-tracking/my-action-plan/save-pdf` retorna **501 — não implementado**.
</Warning>

### PUT /mentored-tracking/my-tasks/\{task_number\}

<ParamField body="completed" type="boolean" required>Tarefa concluída ou não.</ParamField>
<ParamField body="month" type="string">Mês de referência (opcional; padrão: mês atual).</ParamField>

### Análises por IA

Analisam respostas de testes com OpenAI e persistem o resultado em `mentored_profiles`.

| Método | Path | Descrição | Auth |
|---|---|---|---|
| POST | `/mentored-tracking/analyze-disc` | Análise DISC | JWT |
| POST | `/mentored-tracking/analyze-socioemocional` | Análise socioemocional | JWT |
| POST | `/mentored-tracking/analyze-procrastination` | Análise de procrastinação | JWT |
| POST | `/mentored-tracking/analyze-attention-memory` | Análise atenção/memória | JWT |

#### POST /mentored-tracking/analyze-disc

<ParamField body="answers" type="object" required>Respostas do questionário DISC.</ParamField>

#### POST /mentored-tracking/analyze-attention-memory

<ParamField body="digitSpanResults" type="object" required>Resultados do teste digit span.</ParamField>
<ParamField body="stroopResults" type="object" required>Resultados do teste de Stroop.</ParamField>

## Career Booster (`/career-booster`)

Gestão de carreira dos funcionários de offices apoiadores (perfis, trilhas de carreira e PDIs).

| Método | Path | Descrição | Auth |
|---|---|---|---|
| GET | `/career-booster/offices/my` | Meus offices | JWT |
| GET | `/career-booster/offices/{office_id}/employees` | Funcionários do office | JWT |
| PATCH | `/career-booster/offices/{office_id}/employees/{member_id}/profile` | Atualizar perfil do funcionário | JWT |
| GET | `/career-booster/offices/{office_id}/employees/{member_id}/pdis` | Listar PDIs | JWT |
| POST | `/career-booster/offices/{office_id}/employees/{member_id}/pdis` | Criar PDI | JWT |
| PATCH | `/career-booster/pdis/{pdi_id}` | Atualizar PDI | JWT |
