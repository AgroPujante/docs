Lembre a distinção: **users** são contas de acesso (vinculadas ao Supabase Auth), **members** são pessoas físicas (cadastro comercial) e **offices** são escritórios (CNPJ). Veja [Modelos](/escola/modelos).

## Erros comuns

Os erros genéricos da API v2 (401/403/422, shape `{detail, code}`) estão em [Convenções da API](/escola/convencoes) — abaixo, apenas os específicos de cada endpoint.

## Users (`/users`)

| Método | Path | Descrição | Auth |
|---|---|---|---|
| GET | `/users/profile/me` | Perfil do usuário logado | JWT |
| GET | `/users` | Listar users (`?search`, `?role`) | JWT |
| GET | `/users/{user_id}` | Detalhe de um user | JWT |
| PATCH | `/users/{user_id}` | Atualizar user | JWT |
| DELETE | `/users/{user_id}` | Remover user | JWT |

## Members (`/members`)

| Método | Path | Descrição | Auth |
|---|---|---|---|
| GET | `/members` | Listar members (`?search`, `?status`) | MANAGER |
| POST | `/members` | Criar member | MANAGER |
| PATCH | `/members/{member_id}` | Atualizar member | MANAGER |
| DELETE | `/members/{member_id}` | Remover member | MANAGER |
| POST | `/members/send-email` | Envio de email em massa | MANAGER |
| GET | `/members/email-logs` | Histórico de emails (`?emailType`, `?limit`, `?offset`) | MANAGER |
| POST | `/members/bulk-assign-plan` | Atribuir plano em massa | MANAGER |
| POST | `/members/bulk-create-users` | Criar users em massa | MANAGER |

<Warning>
`POST /members/bulk-create-users` retorna **501 — não implementado**.
</Warning>
