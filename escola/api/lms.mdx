Base: `/api/v2/lms` (certificados em `/api/v2/lessons` e `/api/v2/certificates`). Rotas sob `/lms/catalog/*` são a visão do **aluno**; as demais são administração de conteúdo.

## Erros comuns

Erros de `HTTPException`/`AppException` saem com `detail` + `code` (handler global em `core/exceptions.py`). O 422 de validação segue o shape padrão do FastAPI.

```json title="401 Unauthorized"
{ "detail": "Token de autenticacao nao fornecido", "code": "http_error" }
```

```json title="403 Forbidden (rota MANAGER sem role ADMIN/COMMUNITY_MANAGER)"
{ "detail": "Acesso restrito", "code": "http_error" }
```

```json title="422 Unprocessable Entity"
{ "detail": [{ "loc": ["body", "name"], "msg": "field required", "type": "missing" }] }
```

Uploads dependem do Bunny: se não configurado, retornam `503 { "detail": "Bunny Storage não configurado" }` (ou `"Bunny Stream não configurado"` no upload de vídeo).

## Comentários

| Método | Path | Descrição | Auth |
|---|---|---|---|
| GET | `/lms/catalog/lessons/{lesson_id}/comments` | Listar comentários da aula | JWT |
| POST | `/lms/catalog/lessons/{lesson_id}/comments` | Criar comentário | JWT |
| GET | `/lms/admin/comments` | Listar todos (`?filter`, `?search`, `?page`, `?limit`) | MANAGER |
| GET | `/lms/admin/comments/unanswered-count` | Contar não respondidos | MANAGER |
| POST | `/lms/admin/comments/{comment_id}/reply` | Responder comentário | MANAGER |
| DELETE | `/lms/admin/comments/{comment_id}` | Deletar comentário | MANAGER |

## Certificados

| Método | Path | Descrição | Auth |
|---|---|---|---|
| POST | `/lessons/{lesson_id}/certificate` | Emitir certificado | JWT |
| GET | `/certificates/{codigo}` | Verificar autenticidade de certificado | Público |

### Exemplos

<AccordionGroup>

<Accordion title="POST /api/v2/lessons/{lesson_id}/certificate">

Emissão idempotente — exige ≥ 75% dos tópicos da aula concluídos.

```bash title="Requisição"
curl -X POST "https://api.escolapujante.com.br/api/v2/lessons/c3d4e5f6-a7b8-4c9d-0e1f-2a3b4c5d6e7f/certificate" \
  -H "Authorization: Bearer eyJ..."
```

```json title="200 OK"
{
  "codigo": "EP-2026-A3F9C1",
  "alunoNome": "Ana Carolina Souza",
  "aulaNome": "Arrendamento rural na prática",
  "data": "12 de junho de 2026",
  "emitidoEm": "2026-06-12T11:30:02.881000+00:00"
}
```

```json title="403 Forbidden (progresso insuficiente)"
{ "detail": "Progresso insuficiente para emitir certificado (50% concluido, minimo 75%).", "code": "forbidden" }
```

```json title="403 Forbidden (aula sem tópicos)"
{ "detail": "Esta aula nao possui topics cadastrados; nao e possivel emitir certificado.", "code": "forbidden" }
```

```json title="404 Not Found"
{ "detail": "Aula nao encontrado", "code": "not_found" }
```

```json title="409 Conflict"
{ "detail": "Nao foi possivel gerar codigo unico apos 5 tentativas.", "code": "conflict" }
```

</Accordion>
