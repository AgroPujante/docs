Base: `/api/v2/lms` (certificados em `/api/v2/lessons` e `/api/v2/certificates`). Rotas sob `/lms/catalog/*` são a visão do **aluno**; as demais são administração de conteúdo.

## Catálogo (aluno)

| Método | Path | Descrição | Auth |
|---|---|---|---|
| GET | `/lms/catalog` | Catálogo de trilhas/cursos (`?kind`) | JWT |
| GET | `/lms/catalog/{track_id}` | Detalhe de trilha | JWT |
| GET | `/lms/catalog/progress/recent` | "Continue assistindo" (`?limit`) | JWT |

## Tracks (admin)

| Método | Path | Descrição | Auth |
|---|---|---|---|
| GET | `/lms/tracks` | Listar tracks (`?kind`) | MANAGER |
| POST | `/lms/tracks` | Criar track | MANAGER |
| GET | `/lms/tracks/{track_id}` | Detalhe | MANAGER |
| PATCH | `/lms/tracks/{track_id}` | Atualizar | MANAGER |
| DELETE | `/lms/tracks/{track_id}` | Remover | MANAGER |
| POST | `/lms/tracks/{track_id}/cover` | Upload de cover (multipart) | MANAGER |

### POST /lms/tracks

<ParamField body="name" type="string" required>Nome da trilha.</ParamField>
<ParamField body="kind" type="string" required>`track`, `imersion` ou `course_of_month`.</ParamField>
<ParamField body="description" type="string">Descrição.</ParamField>
<ParamField body="coverImageUrl" type="string">URL da capa.</ParamField>
<ParamField body="order" type="number">Ordem de exibição.</ParamField>
<ParamField body="active" type="boolean">Ativa no catálogo.</ParamField>
