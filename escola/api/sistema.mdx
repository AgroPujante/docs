## Erros comuns

Todos os endpoints autenticados podem retornar os shapes abaixo (FastAPI + handler global, que acrescenta o campo `code`):

```json title="401 Unauthorized — sem token"
{ "detail": "Token de autenticacao nao fornecido", "code": "http_error" }
```

```json title="401 Unauthorized — token inválido ou usuário não mapeado"
{ "detail": "Token invalido ou expirado", "code": "http_error" }
```

Também pode ocorrer `{ "detail": "Usuario nao mapeado. Contate o suporte." }` quando o JWT é válido mas não há registro em `pujante.users`.

```json title="403 Forbidden — role insuficiente (MANAGER/ADMIN)"
{ "detail": "Acesso restrito", "code": "http_error" }
```

```json title="422 Unprocessable Entity — validação Pydantic"
{
  "detail": [
    { "type": "missing", "loc": ["body", "campo"], "msg": "Field required", "input": {} }
  ]
}
```

Validações de negócio respondem 422 com `{ "detail": "...", "code": "validation_error" }`. Nos accordions abaixo, os erros genéricos não são repetidos — apenas os específicos de cada endpoint.

## Docs wiki (`/docs`)

Wiki interna armazenada em `doc_sections`.

| Método | Path | Descrição | Auth |
|---|---|---|---|
| GET | `/docs` | Listar docs publicados | Público |
| GET | `/docs/admin` | Listar todos (incl. rascunhos) | MANAGER |
| GET | `/docs/{slug}` | Detalhe por slug | Público |
| POST | `/docs` | Criar doc | MANAGER |
| PATCH | `/docs/{doc_id}` | Atualizar doc | MANAGER |
| DELETE | `/docs/{doc_id}` | Remover doc | MANAGER |
| POST | `/docs/seed` | Seed da estrutura padrão | MANAGER |

</Warning>

