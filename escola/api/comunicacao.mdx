## Erros comuns

Os erros genéricos da API v2 (401/403/422, shape `{detail, code}`) estão em [Convenções da API](/escola/convencoes) — abaixo, apenas os específicos de cada endpoint.

## Email campaigns (`/email-campaigns`)

Envios em massa via Resend, com logs em `email_campaign_logs`. Disparos são assíncronos (respondem `202 Accepted`).

| Método | Path | Descrição | Auth |
|---|---|---|---|
| GET | `/email-campaigns` | Listar campanhas | MANAGER |
| POST | `/email-campaigns` | Criar campanha | MANAGER |
| GET | `/email-campaigns/{campaign_id}` | Detalhe | MANAGER |
| GET | `/email-campaigns/{campaign_id}/analytics` | Analytics da campanha | MANAGER |
| POST | `/email-campaigns/{campaign_id}/send` | Disparar (202) | MANAGER |
| POST | `/email-campaigns/{campaign_id}/test` | Envio de teste | MANAGER |
| POST | `/email-campaigns/{campaign_id}/retry-failed` | Retry de falhos (202) | MANAGER |
| POST | `/email-campaigns/aula-hoje` | Campanha rápida "aula hoje" (202) | MANAGER |
| POST | `/email-campaigns/recipient-count` | Contar destinatários de um filtro | MANAGER |
| DELETE | `/email-campaigns/{campaign_id}` | Remover campanha | MANAGER |

<Accordion title="POST /api/v2/email-campaigns">
```bash title="Requisição"
curl -X POST "https://api.escolapujante.com.br/api/v2/email-campaigns" \
  -H "Authorization: Bearer <TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
    "subject": "Novidades da Escola Pujante — Junho",
    "htmlContent": "<h1>Olá!</h1><p>Confira as novidades...</p>",
    "recipientFilter": "{\"productTypes\":[\"MEMBERS_CLUB\",\"OFFICE_SUPPORTER\"]}"
  }'
```

`recipientFilter` é uma **string JSON** (não objeto). Chaves suportadas: `productTypes`, `memberIds` e `emails` (este último sobrescreve os demais).

## Calendar (`/calendar`)

|---|---|---|---|
| GET | `/calendar` | Listar eventos (`?fromDate`, `?toDate`) | JWT |
| GET | `/calendar/{event_id}` | Detalhe de evento | JWT |

| PATCH | `/calendar/{event_id}` | Atualizar evento | MANAGER |

| POST | `/calendar/{event_id}/image` | Upload de imagem (multipart) | MANAGER |
