<Note>
A **criação de cobranças recorrentes** nos gateways (Asaas/PagarMe) ainda vive no NestJS legado. O v2 cuida da gestão local de subscriptions, imports gateway → local, webhooks e checkout.
</Note>

## Erros comuns

Os erros genéricos da API v2 (401/403/422, shape `{detail, code}`) estão em [Convenções da API](/escola/convencoes) — abaixo, apenas os específicos de cada endpoint.

## Subscriptions (`/subscriptions`)

| Método | Path | Descrição | Auth |
|---|---|---|---|
| GET | `/subscriptions` | Listar (`?productType`, `?officeId`, `?memberId`, `?status`) | MANAGER |
| POST | `/subscriptions` | Criar subscription | MANAGER |
| GET | `/subscriptions/{subscription_id}` | Detalhe | MANAGER |
| PATCH | `/subscriptions/{subscription_id}` | Atualizar | MANAGER |
| DELETE | `/subscriptions/{subscription_id}` | Remover | MANAGER |
| PATCH | `/subscriptions/{subscription_id}/activate` | Ativar | MANAGER |
| PATCH | `/subscriptions/{subscription_id}/cancel` | Cancelar | MANAGER |
| PATCH | `/subscriptions/{subscription_id}/pause` | Pausar | MANAGER |
| PATCH | `/subscriptions/{subscription_id}/churn` | Marcar churn | MANAGER |
| GET | `/subscriptions/{subscription_id}/payments` | Histórico de pagamentos | MANAGER |
| GET | `/subscriptions/my` | Minhas subscriptions | JWT |
| GET | `/subscriptions/my/payments/{subscription_id}` | Meus pagamentos | JWT |
| GET | `/subscriptions/asaas` | Consulta direta no Asaas | MANAGER |
| POST | `/subscriptions/webhook/asaas` | Webhook Asaas | Público (token) |
| POST | `/subscriptions/webhook/pagarme` | Webhook PagarMe | Público (token) |
| POST | `/subscriptions/asaas/import` | Sync Asaas → local (retorna 202) | MANAGER |
| GET | `/subscriptions/asaas/import-status` | Status do import (`?productType`) | MANAGER |
| POST | `/subscriptions/asaas/backfill-member-contacts` | Preencher phone/cpf (`?limit`) | MANAGER |
| POST | `/subscriptions/pagarme/import` | Sync PagarMe → local (retorna 202) | MANAGER |
| GET | `/subscriptions/pagarme/import-status` | Status do import | MANAGER |
| POST | `/subscriptions/asaas/sync-payments` | Sync de pagamentos | MANAGER |
| POST | `/subscriptions/process-expired` | Processar expiradas | MANAGER |

<Warning>
Retornam **501 — não implementado**: `GET /subscriptions/asaas`, `POST /subscriptions/asaas/sync-payments` e `POST /subscriptions/process-expired`.
</Warning>

<ParamField body="officeId" type="string">ID do office (assinaturas de escritório).</ParamField>
<ParamField body="memberId" type="string">ID do member (assinaturas individuais).</ParamField>

<ParamField body="endDate" type="string">Data de fim (ISO).</ParamField>
<ParamField body="status" type="string">Status inicial.</ParamField>

<ParamField body="churnDate" type="string" required>Data do churn.</ParamField>
<ParamField body="reason" type="string">Motivo.</ParamField>

### POST /subscriptions/asaas/import

Dispara sync assíncrono (responde `202 Accepted`); acompanhe via `GET /subscriptions/asaas/import-status`.

<ParamField body="startDate" type="string">Filtro de início (opcional).</ParamField>
<ParamField body="endDate" type="string">Filtro de fim (opcional).</ParamField>
<ParamField body="productType" type="string">Restringir a um produto (opcional).</ParamField>

## Coupons (`/coupons`)

| Método | Path | Descrição | Auth |
|---|---|---|---|
| GET | `/coupons/validate/{code}` | Validar cupom | Público |
| GET | `/coupons` | Listar (`?isActive`, `?productId`, `?dateFrom`, `?dateTo`) | ADMIN |
| GET | `/coupons/impact` | Análise de impacto | ADMIN |

| PATCH | `/coupons/{coupon_id}` | Atualizar | ADMIN |

## Webhooks externos

| Método | Path | Descrição | Auth |
|---|---|---|---|
| POST | `/subscriptions/webhook/asaas` | Eventos Asaas (auditado em `asaas_webhook_events`) | Público (token `ASAAS_WEBHOOK_TOKEN`) |
| POST | `/subscriptions/webhook/pagarme` | Eventos PagarMe (auditado em `pagarme_webhook_events`) | Público (token `PAGARME_WEBHOOK_TOKEN`) |
| POST | `/webhooks/resend` | Eventos Resend (entregas, bounces) | Público (assinatura Svix HMAC) |

### Exemplos

<AccordionGroup>

<Accordion title="POST /api/v2/subscriptions/webhook/asaas">

Exemplo completo na seção [Subscriptions](#subscriptions-subscriptions). Resumo:

```bash title="Requisição"
curl -X POST "https://api.escolapujante.com.br/api/v2/subscriptions/webhook/asaas" \
  -H "asaas-access-token: <TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{ "event": "PAYMENT_RECEIVED", "payment": { "id": "pay_1234567890", "subscription": "sub_abc123" } }'
```

```json title="200 OK"
{ "received": true, "processed": true }
```

Payload sem `event` ou `payment` retorna `{ "received": true, "processed": false }`. Erros: `401 { "detail": "Token de webhook invalido." }`, `400 { "detail": "JSON invalido." }`.

</Accordion>

<Accordion title="POST /api/v2/subscriptions/webhook/pagarme">

Exemplo completo na seção [Subscriptions](#subscriptions-subscriptions). Resumo:

```bash title="Requisição"
curl -X POST "https://api.escolapujante.com.br/api/v2/subscriptions/webhook/pagarme" \
  -H "x-webhook-token: <TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{ "type": "charge.paid", "data": { "id": "ch_9XyZaB1cD2eF3gH4" } }'
```

```json title="200 OK"
{ "received": true, "processed": true }
```

Erros: `401 { "detail": "Token de webhook invalido." }`, `400 { "detail": "JSON invalido." }`.

</Accordion>

<Accordion title="POST /api/v2/webhooks/resend">

Chamado pelo Resend com headers Svix (não chame manualmente em produção).

```bash title="Requisição"
curl -X POST "https://api.escolapujante.com.br/api/v2/webhooks/resend" \
  -H "svix-id: msg_2f8a..." \
  -H "svix-timestamp: 1781262000" \
  -H "svix-signature: v1,K5oZ..." \
  -H "Content-Type: application/json" \
  -d '{ "type": "email.delivered", "created_at": "2026-06-12T11:30:02.881Z", "data": { "email_id": "8f3b2c1d-..." } }'
```

```json title="200 OK"
{ "ok": true, "event": "email.delivered" }
```

Eventos não rastreados retornam `{ "ok": true, "skipped": "event_not_tracked" }`; payload sem `email_id` retorna `{ "ok": true, "skipped": "no_email_id" }`.

```json title="400 Bad Request"
{ "detail": "Headers Svix ausentes.", "code": "http_error" }
```

```json title="401 Unauthorized"
{ "detail": "Assinatura invalida.", "code": "http_error" }
```

```json title="503 Service Unavailable"
{ "detail": "Webhook nao configurado.", "code": "http_error" }
```

</Accordion>
