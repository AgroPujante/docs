Quatro grupos de rotas: `/dashboard/financial` (métricas de negócio), `/dashboard` (billing unificado dos gateways), `/financial` (relatórios) e `/bling` (NFSe).

## Erros comuns

Todos os endpoints autenticados podem retornar os shapes abaixo (FastAPI + handler global, que acrescenta o campo `code`):

```json title="401 Unauthorized — sem token"
{ "detail": "Token de autenticacao nao fornecido", "code": "http_error" }
```

```json title="401 Unauthorized — token inválido ou usuário não mapeado"
{ "detail": "Token invalido ou expirado", "code": "http_error" }
```

Também pode ocorrer `{ "detail": "Usuario nao mapeado. Contate o suporte." }` quando o JWT é válido mas não há registro em `pujante.users`.

```json title="403 Forbidden — role insuficiente (MANAGER/ADMIN)"
{ "detail": "Acesso restrito", "code": "http_error" }
```

```json title="422 Unprocessable Entity — validação Pydantic"
{
  "detail": [
    { "type": "missing", "loc": ["query", "month"], "msg": "Field required", "input": null }
  ]
}
```

Nos accordions abaixo, esses erros genéricos não são repetidos — apenas os erros específicos de cada endpoint.

## Dashboard billing (`/dashboard`)

| Método | Path | Descrição | Auth |
|---|---|---|---|
| GET | `/dashboard/balance` | Saldo unificado dos gateways | MANAGER |
| GET | `/dashboard/balance/extract` | Extrato (`?dateFrom`, `?dateTo`) | MANAGER |
| GET | `/dashboard/balance/receivables` | Recebíveis (`?dateFrom`, `?dateTo`) | MANAGER |
| GET | `/dashboard/balance/cash-flow` | Fluxo de caixa (`?dateFrom`, `?dateTo`) | MANAGER |
| GET | `/dashboard/billing-rules` | Regras de cobrança | MANAGER |
| PATCH | `/dashboard/billing-rules/{rule_id}` | Atualizar regra | MANAGER |
| GET | `/dashboard/chargebacks` | Chargebacks (`?page`, `?limit`) | MANAGER |
| POST | `/dashboard/chargebacks/{chargeback_id}/dispute` | Contestar chargeback | MANAGER |
| GET | `/dashboard/history` | Histórico de pagamentos (`?dateFrom`, `?dateTo`, `?status`, `?gateway`, `?limit`) | MANAGER |
| GET | `/dashboard/payments` | Alias de `/history` | MANAGER |
| GET | `/dashboard/payments/failures` | Falhas de pagamento (`?dateFrom`, `?dateTo`) | MANAGER |
| GET | `/dashboard/payments/refunds` | Reembolsos (`?dateFrom`, `?dateTo`) | MANAGER |
| POST | `/dashboard/payments/refund` | Executar reembolso | MANAGER |
| GET | `/dashboard/payment-links` | Links de pagamento (`?page`, `?limit`) | MANAGER |
| POST | `/dashboard/payment-links` | Criar link de pagamento | MANAGER |
| DELETE | `/dashboard/payment-links/{link_id}` | Remover link | MANAGER |
| POST | `/dashboard/subscription-mgmt/{subscription_id}/sync` | Sync com gateway | MANAGER |
| POST | `/dashboard/subscription-mgmt/{subscription_id}/update-card` | Atualizar cartão | MANAGER |
| POST | `/dashboard/subscription-mgmt/{subscription_id}/retry-payment` | Reprocessar pagamento | MANAGER |
| GET | `/financial/office-delinquency` | Inadimplência de apoiadores (rota vive no router `/financial`) | MANAGER |

<Warning>
Retornam **501 — não implementado**: `GET/PATCH /billing-rules*`, `POST /chargebacks/{id}/dispute`, `POST /payments/refund`, `POST /payment-links`, `DELETE /payment-links/{link_id}` e os três `POST /subscription-mgmt/{id}/*` (essas operações ainda vivem no NestJS legado).
</Warning>
