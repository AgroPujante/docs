Dois grupos de rotas: `/dashboard/financial` (KPIs, churn, performance e balanço de offices) e `/financial` (relatórios, históricos e KPIs de receita). O billing unificado dos gateways está em [Billing](/escola/api/billing) e a emissão de NFSe em [NFSe (Bling)](/escola/api/nfse).

## Erros comuns

Os erros genéricos da API v2 (401/403/422, shape `{detail, code}`) estão em [Convenções da API](/escola/convencoes) — abaixo, apenas os específicos de cada endpoint.

## Dashboard financial (`/dashboard/financial`)

| Método | Path | Descrição | Auth |
|---|---|---|---|
| GET | `/dashboard/financial/kpis` | KPIs financeiros (`?dateFrom`, `?dateTo`) | MANAGER |
| GET | `/dashboard/financial/health` | Saúde financeira (`?dateFrom`, `?dateTo`) | MANAGER |
| GET | `/dashboard/financial/growth` | Crescimento (`?dateFrom`, `?dateTo`) | MANAGER |
| GET | `/dashboard/financial/lifecycle` | Ciclo de vida (`?dateFrom`, `?dateTo`) | MANAGER |
| GET | `/dashboard/financial/churn` | Churn (`?dateFrom`, `?dateTo`) | MANAGER |
| GET | `/dashboard/financial/member-performance` | Overview de performance de members | MANAGER |
| GET | `/dashboard/financial/member-performance/{member_id}` | Detalhe por member | MANAGER |
| GET | `/dashboard/financial/newsletter-performance` | Performance de newsletters | MANAGER |
| GET | `/dashboard/financial/newsletter-performance/{campaign_id}` | Detalhe por campanha | MANAGER |
| GET | `/dashboard/financial/engagement-ranking` | Ranking de engajamento | MANAGER |
| GET | `/dashboard/financial/offices-balance` | Balanço de offices (`?period`, `?month`) | MANAGER |
| GET | `/dashboard/financial/offices-balance/pdf` | Exportar balanço em PDF | MANAGER |

<Warning>
Retornam **501 — não implementado**: `/clients`, `/products`, `/subscriptions`, `/charges`, `/events`, `/payments-by-product-status`, `/charges-kpis`, `/test-profiles` (GET e PATCH), `/product-mapping`, `/reconcile` e `/operational-alerts`.
</Warning>

Os endpoints 501 deste grupo respondem todos com o mesmo template, mudando apenas o método Nest equivalente:

```json title="501 Not Implemented (template)"
{
  "detail": "Endpoint financial nao migrado ainda. Equivalente no Nest legado: FinancialService.<metodo>. Implementar via funcao SQL em migrations/0002_financial_functions.sql.",
  "code": "http_error"
}
```
