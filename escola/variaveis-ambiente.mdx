<Warning>
Esta página lista apenas os **nomes** das variáveis. Nunca documente valores, chaves ou segredos. Os valores vivem nos `.env` (gitignored) e no provedor de deploy.
</Warning>

## Backend (FastAPI)

### Supabase

| Variável | Uso |
|---|---|
| `SUPABASE_URL` | URL do projeto |
| `SUPABASE_ANON_KEY` | Chave anônima (operações com RLS) |
| `SUPABASE_SERVICE_ROLE_KEY` | Chave service role (bypass RLS) |
| `SUPABASE_JWT_SECRET` | Segredo JWT do projeto |
| `SUPABASE_SCHEMA` | Schema de trabalho (`pujante`) |

### Aplicação

| Variável | Uso |
|---|---|
| `DEBUG` | Habilita Swagger/ReDoc/OpenAPI (desativado em produção) |
| `PORT` | Porta do Uvicorn |
| `ALLOWED_ORIGINS` | Origens permitidas no CORS |
| `RATE_LIMIT_PER_MINUTE` | Limite de requisições por minuto (padrão 60) |
| `FRONTEND_URL` | URL do frontend (links em emails, redirects) |
| `INTERNAL_API_TOKEN` | Token para chamadas sistema-a-sistema |

### Pagamentos

| Variável | Uso |
|---|---|
| `PAGARME_SECRET_KEY` | API PagarMe (server) |
| `PAGARME_PUBLIC_KEY` | API PagarMe (client) |
| `PAGARME_WEBHOOK_TOKEN` | Validação do webhook PagarMe |
| `ASAAS_API_KEY` | API Asaas |
| `ASAAS_BASE_URL` | Base URL Asaas (sandbox/prod) |
| `ASAAS_WEBHOOK_TOKEN` | Validação do webhook Asaas |

## Frontend (Vite)

| Variável | Uso |
|---|---|
| `VITE_API_BASE_URL` | Base da API v2 — dev: `http://localhost:8001/api/v2` (alinhe com a porta do uvicorn), prod: `https://api.escolapujante.com.br/api/v2` |
| `VITE_SUPABASE_URL` | URL do projeto Supabase (mesma do backend) |
| `VITE_SUPABASE_ANON_KEY` | Chave anônima do Supabase (pública por design) |
