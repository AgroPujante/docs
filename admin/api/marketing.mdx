Endpoints de aquisição que alimentam a aba Marketing do painel. Quase todos aceitam **JWT Bearer ou API Key read-only** (coluna Auth = JWT/Key). Veja [Autenticação](/admin/autenticacao).

<Note>
A URL base `https://admin-api.pujante.com.br` usada nos exemplos é **ilustrativa** — a base real depende do deploy no Railway.
</Note>

<Note>
O parâmetro `origin` aparece em vários endpoints e filtra por produto: `site` (AgroPujante), `escola` ou `all` (default na maioria) — veja [Convenções](/admin/convencoes#parametro-origin).
</Note>

## Erros comuns

Os shapes 401/403/422 são os padrões da API — veja [Convenções](/admin/convencoes#erros-comuns). Os exemplos por endpoint referenciam essa página em vez de repeti-los.

## Marketing

| Método | Path | Descrição | Auth |
|---|---|---|---|
| GET | `/admin/marketing/summary` | Visits, signups, paid, MRR, CAC, LTV, ROAS + badge de cortesias | JWT/Key |

## Meta Ads

<Warning>
Requer as variáveis `META_*` configuradas. Sem elas, os endpoints retornam vazio com um aviso — veja [Variáveis de ambiente](/admin/variaveis-ambiente).
</Warning>

| Método | Path | Descrição | Auth |
|---|---|---|---|
| GET | `/admin/meta-ads/summary` | Spend, vendas, custo/compra, ROAS, CPM, CTR + série diária | JWT/Key |
| GET | `/admin/meta-ads/by-creative` | Performance por criativo, com thumbnail | JWT/Key |
| GET | `/admin/meta-ads/funnel` | Criativos → Pág. Vendas → Checkout → Vendas | JWT/Key |
| GET | `/admin/meta-ads/daily-economics` | ROAS · CAC · RL diário (spend Meta + receita Asaas) | JWT/Key |
| POST | `/admin/meta-ads/sync` | Sync manual, assíncrono (responde 202) | JWT |

### GET /admin/meta-ads/summary

<ParamField query="days" type="integer">
Janela em dias, entre 1 e 365. Alternativa ao intervalo explícito.
</ParamField>

<ParamField query="start_date" type="string">
Início do intervalo (`YYYY-MM-DD`). Usar junto com `end_date`.
</ParamField>

<ParamField query="end_date" type="string">
Fim do intervalo (`YYYY-MM-DD`).
</ParamField>

### GET /admin/meta-ads/funnel

<ParamField query="adset_id" type="string">
Restringe o funil a um conjunto de anúncios.
</ParamField>

<ParamField query="plan" type="string" default="all">
Plano: `all`, `monthly`, `semiannual` ou `annual`.
</ParamField>

### POST /admin/meta-ads/sync

<ParamField query="days" type="integer">
Lookback do sync manual, entre 1 e 90 dias.
</ParamField>

<Accordion title="POST /admin/meta-ads/sync">
Escrita: **somente JWT**. Uma API key recebe **403** (veja [Erros comuns](/admin/convencoes#erros-comuns)).

```bash title="Requisição (JWT)"
curl -X POST "https://admin-api.pujante.com.br/admin/meta-ads/sync?days=30" \
  -H "Authorization: Bearer <TOKEN>"
```

```json title="202 Accepted"
{ "fetched": 1240, "upserted": 1240 }
```

Se as variáveis `META_*` não estiverem configuradas ou a Meta API falhar, o sync responde **202** com stats zeradas (no-op, sem erro):

```json title="202 Accepted — não configurado / falha na Meta API"
{ "fetched": 0, "upserted": 0 }
```

`days` fora de 1–90 retorna **422**.
</Accordion>
