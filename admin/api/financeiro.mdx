Endpoints financeiros e de base de usuários que alimentam os dashboards. Quase todos aceitam **JWT Bearer ou API Key read-only** (coluna Auth = JWT/Key). Veja [Autenticação](/admin/autenticacao).

<Note>
A URL base `https://admin-api.pujante.com.br` usada nos exemplos é **ilustrativa** — a base real depende do deploy no Railway.
</Note>

<Note>
O parâmetro `origin` aparece em vários endpoints e filtra por produto: `site` (AgroPujante), `escola` ou `all` (default na maioria) — veja [Convenções](/admin/convencoes#parametro-origin).
</Note>

## Erros comuns

Os shapes 401/403/422 são os padrões da API — veja [Convenções](/admin/convencoes#erros-comuns). Os exemplos por endpoint referenciam essa página em vez de repeti-los.

## Financial

| Método | Path | Descrição | Auth |
|---|---|---|---|
| GET | `/admin/financial` | MRR/ARR + movimentos + cashflow + breakdown por plano | JWT/Key |
| GET | `/admin/financial/by-gateway` | GMV PAID por gateway (Asaas, Pagar.me, Hotmart) | JWT/Key |
| GET | `/admin/financial/consolidado` | Receita consolidada fiel ao painel (Apoiadores + Escola + PRO) | JWT/Key |

### GET /admin/financial

<ParamField query="origin" type="string" default="all">
Produto: `site`, `escola` ou `all`.
</ParamField>

<ParamField query="period_days" type="integer">
Janela de análise, entre 7 e 90 dias.
</ParamField>

<ParamField query="origin" type="string">
Produto de origem do assinante.
</ParamField>

Itens por página, de 1 a 200.

<ParamField query="offset" type="integer" default="0">

</ParamField>
