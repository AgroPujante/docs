Estes endpoints cobrem a operação interna do time. A maioria exige **JWT Bearer** (escrita nunca aceita API key). Veja [Autenticação](/admin/autenticacao).

<Note>
A URL base `https://admin-api.pujante.com.br` usada nos exemplos é **ilustrativa** — a base real depende do deploy no Railway.
</Note>

## Erros comuns

Shapes padrão do FastAPI, válidos para todos os endpoints desta página. Os exemplos por endpoint referenciam esta seção em vez de repeti-los.

```json title="401 Unauthorized — sem credencial"
{ "detail": "nao autenticado" }
```

```json title="401 Unauthorized — JWT inválido ou expirado"
{ "detail": "token invalido: Signature has expired" }
```

```json title="401 Unauthorized — API key inválida, revogada ou expirada"
{ "detail": "API key invalida ou expirada" }
```

```json title="403 Forbidden — email fora de ALLOWED_ADMIN_EMAILS"
{ "detail": "usuario nao autorizado" }
```

Caso específico do Admin: API key tentando um método de **escrita** (POST/PATCH/PUT/DELETE) — a chave é read-only e só passa em GET. Como quase tudo nesta página é escrita, API key praticamente não serve aqui:

```json title="403 Forbidden — API key em método de escrita"
{ "detail": "API key e somente leitura — apenas requisicoes GET sao permitidas" }
```

```json title="422 Unprocessable Entity — validação de body/params"
{
  "detail": [
    {
      "type": "string_too_short",
      "loc": ["body", "problema"],
      "msg": "String should have at least 1 character",
      "input": "",
      "ctx": { "min_length": 1 }
    }
  ]
}
```

## Tickets

Tickets internos de suporte/incidentes, gravados em `pujante.admin_tickets`.

| Método | Path | Descrição | Auth |
|---|---|---|---|
| GET | `/admin/tickets` | Lista tickets com filtros | JWT |
| POST | `/admin/tickets` | Cria ticket | JWT |
| PATCH | `/admin/tickets/{id}` | Atualização parcial; marcar resolvido grava `resolvido_em` | JWT |
| DELETE | `/admin/tickets/{id}` | Remove ticket | JWT |

### GET /admin/tickets

<ParamField query="status" type="string">
`aberto` ou `resolvido`.
</ParamField>

<ParamField query="sistema" type="string">
`agropujante`, `escola` ou `geral`.
</ParamField>

<ParamField query="prioridade" type="string">
`baixa`, `media` ou `alta`.
</ParamField>

### POST /admin/tickets

<ParamField body="data" type="string" required>
Data do ocorrido.
</ParamField>

<ParamField body="responsavel_nome" type="string" required>
Nome de quem reportou. Também aceita `responsavel_email` e `responsavel_telefone`.
</ParamField>

<ParamField body="sistema" type="string" required>
`agropujante`, `escola` ou `geral`.
</ParamField>

<ParamField body="prioridade" type="string" required>
`baixa`, `media` ou `alta`.
</ParamField>

<ParamField body="problema" type="string" required>
Descrição do problema.
</ParamField>

<ParamField body="observacao" type="string">
Observações adicionais.
</ParamField>

<ParamField body="imagens" type="array">
URLs de imagens anexadas.
</ParamField>

## Panel access

Gestão de membros e cargos do painel (RBAC). Detalhes em [Autenticação](/admin/autenticacao#rbac-cargos-do-painel).

| Método | Path | Descrição | Auth |
|---|---|---|---|
| GET | `/admin/panel-access/me` | Cargo do logado; auto-provisiona no primeiro acesso | JWT |
| GET | `/admin/panel-access/members` | Lista membros | JWT (administrador) |
| POST | `/admin/panel-access/members` | Adiciona membro `{email, cargo}` | JWT |
| DELETE | `/admin/panel-access/members/{member_id}` | Remove membro | JWT |
| GET | `/admin/panel-access/logs` | Últimas 200 atividades | JWT (administrador ou auditoria) |
| POST | `/admin/panel-access/log-login` | Registra acesso ao painel | JWT |

## Custos

Controle de custos mensais da operação, em `pujante.custos`.

| Método | Path | Descrição | Auth |
|---|---|---|---|
| GET | `/admin/custos/taxonomias` | Listas fixas: categorias, frentes, formas, frequências, status | JWT |

## Launches

Lançamentos cross-product. A leitura é agregada; a **escrita é delegada** ao backend do produto de origem — veja [Arquitetura](/admin/arquitetura#delegacao-de-escrita-launches).

| Método | Path | Descrição | Auth |
|---|---|---|---|
| GET | `/admin/launches` | Lista lançamentos (`?origin, ?kind, ?status, ?limit, ?offset`) | JWT/Key |
| POST | `/admin/launches` | Cria lançamento delegando ao backend de origem | JWT |

### POST /admin/launches

<ParamField body="kind" type="string" required>
Tipo do lançamento — também determina o destino da delegação: `post`, `news`, `newsletter` e `bulletin` vão para o AgroPujante (`site`); `lesson`, `track`, `event` e `broadcast` vão para a Escola. Não existe campo `origin` no body — a origem é derivada do `kind`.
</ParamField>

<ParamField body="title" type="string" required>
Título do lançamento.
</ParamField>

<ParamField body="description" type="string">
Descrição. O `CreateLaunchRequest` aceita campos adicionais conforme o tipo.
</ParamField>

<Note>
O Bearer token do usuário é repassado ao backend de destino. Falha no upstream resulta em **502** com o detalhe do erro.
</Note>

## Proxy genérico

Repassa qualquer chamada para os backends dos produtos, preservando body, query e header `Authorization`.

| Método | Path | Descrição | Auth |
|---|---|---|---|
| GET, POST, PUT, PATCH, DELETE | `/admin/escola/{path}` | Proxy para a API da Escola | JWT |
| GET, POST, PUT, PATCH, DELETE | `/admin/agropujante/{path}` | Proxy para a API do AgroPujante | JWT |

<Note>
Operações de escrita via proxy geram registro assíncrono de auditoria em `admin_activity_log`.
</Note>

<AccordionGroup>
<Accordion title="GET/POST/PUT/PATCH/DELETE /admin/escola/{path}">
O status e o corpo da resposta são os do **upstream** (Escola) — o Admin só repassa.

```bash title="Requisição (JWT) — leitura proxiada"
curl "https://admin-api.pujante.com.br/admin/escola/api/v2/admin/members?limit=20" \
  -H "Authorization: Bearer <TOKEN>"
```

```json title="200 OK — corpo retornado pela API da Escola (shape definido lá)"
{ "...": "resposta da Escola, repassada sem modificação" }
```

Erros próprios do proxy (não do upstream):

```json title="502 Bad Gateway — upstream inacessível"
{ "detail": "falha ao chamar escola: All connection attempts failed" }
```

```json title="503 Service Unavailable — env ausente"
{ "detail": "ESCOLA_API_URL não configurada no backend Pujante-Admin" }
```

Erros 401/403 do próprio Admin (antes de proxiar): veja [Erros comuns](#erros-comuns). Erros 4xx/5xx vindos da Escola são repassados como estão.
</Accordion>
