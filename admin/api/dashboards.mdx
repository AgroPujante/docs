---

Estes endpoints alimentam os dashboards do painel. Quase todos aceitam **JWT Bearer ou API Key read-only** (coluna Auth = JWT/Key). Veja [Autenticação](/admin/autenticacao).

<Note>
A URL base `https://admin-api.pujante.com.br` usada nos exemplos é **ilustrativa** — a base real depende do deploy no Railway.
</Note>

<Note>
O parâmetro `origin` aparece em vários endpoints e filtra por produto: `site` (AgroPujante), `escola` ou `all` (default na maioria).
</Note>

## Erros comuns

Shapes padrão do FastAPI, válidos para todos os endpoints autenticados desta página. Os exemplos por endpoint referenciam esta seção em vez de repeti-los.

```json title="401 Unauthorized — sem credencial"
{ "detail": "nao autenticado" }
```

```json title="401 Unauthorized — JWT inválido ou expirado"
{ "detail": "token invalido: Signature has expired" }
```

```json title="401 Unauthorized — JWT sem claim de email"
{ "detail": "token sem email" }
```

```json title="401 Unauthorized — API key inválida, revogada ou expirada"
{ "detail": "API key invalida ou expirada" }
```

```json title="403 Forbidden — email fora de ALLOWED_ADMIN_EMAILS"
{ "detail": "usuario nao autorizado" }
```

Caso específico do Admin: API key tentando um método de **escrita** (POST/PATCH/DELETE) — a chave é read-only e só passa em GET:

```json title="403 Forbidden — API key em método de escrita"
{ "detail": "API key e somente leitura — apenas requisicoes GET sao permitidas" }
```

```json title="422 Unprocessable Entity — validação de parâmetros"
{
  "detail": [
    {
      "type": "less_than_equal",
      "loc": ["query", "days"],
      "msg": "Input should be less than or equal to 30",
      "input": "90",
      "ctx": { "le": 30 }
    }
  ]
}
```

<Accordion title="GET /health/deep">
```bash title="Requisição (sem auth)"

  "checks": { "jwks": false, "mvs": true, "mvs_count": 9 },
  "ts": "2026-06-12T14:03:24.118273+00:00"

```

<Accordion title="POST /admin/mvs/refresh">
Escrita: **somente JWT**. Uma API key recebe **403** (veja [Erros comuns](#erros-comuns)).

```bash title="Requisição (JWT)"
curl -X POST "https://admin-api.pujante.com.br/admin/mvs/refresh?concurrent=true" \
  -H "Authorization: Bearer <TOKEN>"
```

```json title="200 OK"
{
  "count": 2,
  "results": [
    { "name": "admin_mv_kpis_monthly", "status": "ok", "error": null },
    { "name": "admin_mv_subscribers", "status": "ok", "error": null }
  ]
}
```

Falhas de refresh em uma MV não derrubam a chamada — vêm linha a linha em `results` com `status != "ok"` e o `error` preenchido.
</Accordion>
</AccordionGroup>

## Observability

<Warning>
Requer as variáveis `NEW_RELIC_*` configuradas. Sem elas, os endpoints retornam vazio com um aviso.
</Warning>

| Método | Path | Descrição | Auth |
|---|---|---|---|
| GET | `/admin/observability/metrics` | KPIs, série de erros, top endpoints, distribuição de status | JWT/Key |
| GET | `/admin/observability/error-occurrences` | Drill-down das ocorrências de um erro | JWT/Key |
| GET | `/admin/observability/logs` | Logs via NerdGraph | JWT/Key |

### GET /admin/observability/error-occurrences

<ParamField query="uri" type="string" required>
URI do endpoint com erro a detalhar.
</ParamField>

<ParamField query="origin" type="string">
App de origem: `site` ou `escola`.
</ParamField>

<ParamField query="status" type="integer">
Filtra por status HTTP.
</ParamField>

<ParamField query="method" type="string">
Filtra por método HTTP.
</ParamField>

<ParamField query="minutes" type="integer">
Janela em minutos, entre 1 e 1440.
</ParamField>

<ParamField query="limit" type="integer">
Máximo de ocorrências, entre 1 e 200.
</ParamField>

### GET /admin/observability/logs

<ParamField query="origin" type="string">
App de origem: `site` ou `escola`.
</ParamField>

<ParamField query="level" type="string">
Nível de log único (ex.: `error`).
</ParamField>

<ParamField query="levels" type="string">
Múltiplos níveis, separados por vírgula.
</ParamField>

<ParamField query="minutes" type="integer">
Janela em minutos.
</ParamField>

<ParamField query="query" type="string">
Busca textual nos logs.
</ParamField>

<ParamField query="limit" type="integer">
Máximo de linhas, entre 1 e 500.
</ParamField>

<ParamField query="since_ms" type="integer">
Início da janela em epoch milliseconds (alternativa a `minutes`).
</ParamField>

<ParamField query="until_ms" type="integer">
Fim da janela em epoch milliseconds.
</ParamField>
