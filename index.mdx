## Bem-vindo

Esta é a documentação técnica do ecossistema **Pujante**. Aqui você encontra a referência completa de APIs, arquitetura, autenticação, modelos de dados e integrações de cada produto.

## Produtos

<CardGroup cols={2}>
  <Card title="AgroPujante (Portal)" icon="newspaper" href="/agropujante/overview">
    Portal jurídico do agro com conteúdo editorial — notícias, artigos, julgados, boletins de jurisprudência e podcasts. ~3 mil visitas/dia em produção.
  </Card>
  <Card title="Escola Pujante" icon="graduation-cap" href="/escola/overview">
    LMS + mentoria para advogados do agro. Trilhas, imersões, testes comportamentais, acompanhamento de mentorados e gestão financeira.
  </Card>
  <Card title="Pujante Admin" icon="gauge-high" href="/admin/overview">
    Painel admin unificado que agrega dados do Portal e da Escola — dashboards, financeiro, marketing, Gantt de projetos e observabilidade.
  </Card>
  <Card title="Pujante Mobile" icon="mobile-screen" href="/mobile/overview">
    App mobile (Expo + React Native) que consome as APIs do Portal e da Escola, com gateway duplo e handoff de autenticação.
  </Card>
</CardGroup>

## Visão rápida das APIs

| Produto | Base URL | Stack | Prefixo |
|---------|----------|-------|---------|
| AgroPujante | `api.agropujante.com.br` | FastAPI | `/api/v1` |
| Escola Pujante | `api.escolapujante.com.br` | FastAPI (novo) + NestJS (legado) | `/api/v2` e `/api` |
| Pujante Admin | backend próprio (Railway) | FastAPI agregador | `/admin`, `/gantt` |
| Pujante Mobile | — (cliente) | Expo + React Native | consome v1 e v2 |

<Note>
Todos os produtos compartilham o mesmo banco Supabase (PostgreSQL, schema `pujante`) e autenticação baseada em Supabase Auth (JWT ES256 validado via JWKS).
</Note>
